# Fatture AI — Supabase

Questa cartella contiene schema, migrazioni, funzioni e configurazione della migrazione da Google Sheets/Apps Script a Supabase.

## Stato

- Branch di lavoro: `supabase-migration`
- Database operativo previsto: Supabase PostgreSQL
- Archivio documentale: Google Drive
- Google Sheets: interfaccia food cost, ricette, report e sincronizzazione

## Sicurezza

Non inserire mai in questo repository:

- password del database;
- `service_role` key;
- secret key Supabase;
- chiave Gemini;
- credenziali Google;
- token Apps Script.
